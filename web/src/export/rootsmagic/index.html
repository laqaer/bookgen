Export guide

Export your tree from RootsMagic.

RootsMagic saves any family file as a GEDCOM in a few clicks. The file stays on your computer, and so does everything Gildroot does with it.

Steps checked against RootsMagic’s own help pages on 30 September 2026. Gildroot is independent and not affiliated with RootsMagic.

Steps, in RootsMagic 11

From RootsMagic 11’s help page, “Exporting data.”

  1. Open the RootsMagic file with the people you want on the chart.
  2. Go to the File page, choose Export Data, then GEDCOM File.
  3. Choose where to save the new file: the Default Folder, one of your Recent Folders, or Browse for Destination. Type a file name.
  4. In the GEDCOM Export options, set People to export to the entire database, unless you only want a branch.
  5. Under Privacy options, leave Privatize living people unticked if you want living relatives’ real names on the chart. Gildroot hides living people’s dates by default anyway.
  6. Click OK. The .ged file is saved where you chose.

Stuck?

Still stuck after these? Write to support@gildroot.com and say which step. Please don’t attach your file; we never need it.

The page is called “Files”, not “File”.

RootsMagic’s own help uses both names for the same page. It is the page for opening, creating and exporting files.

Living relatives show as “Living”.

The file was exported with Privatize living people ticked, which can replace their names with the word Living. Export again with it unticked. Your names still stay on your computer.

I only want one branch.

In People to export, choose to select people from a list, or a named group, instead of the entire database.

My tree is on FamilySearch or Ancestry, not in RootsMagic.

RootsMagic can download it first. See the FamilySearch guide, or export from Ancestry directly with the Ancestry guide.

Gildroot reads the text encodings family tree programs use (UTF-8, UTF-16, ANSEL and the older Windows and Mac sets) and works out which one a file uses. If a name still looks wrong in the studio, you can correct it there; your original file is never changed.
