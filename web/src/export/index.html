Export guides

Get your tree out.

Every family tree website and program can save your tree as a GEDCOM file: one plain-text file with every name, date, place and family link. Pick where your tree lives.

Menu names checked against each company’s own help pages on 30 September 2026. Gildroot is independent and not affiliated with any of them.

Guides

  • AncestryTrees, then More, Tree Settings, Export tree. You must be the tree’s owner. Arrives as a .zip.
  • MyHeritageFamily tree, then Manage trees, Export to GEDCOM. Also Family Tree Builder.
  • FamilySearchNo download button. A free program such as RootsMagic Essentials or Ancestral Quest Basics fetches it for you.
  • RootsMagicFile, then Export Data, GEDCOM File.
  • Family Tree MakerFile, then Export, Entire file. Leave the password ZIP off.
  • GrampsFamily Trees, then Export, GEDCOM, in the Export Assistant.
  • GeniFamily, then Share Your Tree, Export. The file arrives by link.
  • WikiTreeMy WikiTree, then GEDCOMs. Your watchlist, or one person’s ancestors.

What a GEDCOM file is

GEDCOM is the standard file format for family trees, used since the 1980s. The file ends in .ged. Inside, it is plain text: each person is a short record of their name, sex, birth, death and family links.

0 @I3@ INDI
1 NAME Rosa Maria /Almeida/
1 SEX F
1 BIRT
2 DATE 3 APR 1921
2 PLAC Fall River, Bristol, Massachusetts, USA

Gildroot reads .ged files (GEDCOM 5.5, 5.5.1 and 7.0), a .zip with a .ged inside, and .gdz files. It reads them on your computer; nothing is uploaded.

Photos don’t travel in a GEDCOM file, and a chart doesn’t need them.
