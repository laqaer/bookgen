Export guide

Export your tree from Family Tree Maker.

Family Tree Maker exports a GEDCOM file from its File menu, on Windows and on Mac. One setting matters for Gildroot: leave the password-protected ZIP option off.

Steps checked against Family Tree Maker’s own help pages on 30 September 2026. Gildroot is independent and not affiliated with Family Tree Maker.

Steps, Windows or Mac

From the Software MacKiev support articles on exporting GEDCOM files in Family Tree Maker. The Windows and Mac steps are the same.

  1. Open your tree. Choose Export from the File menu. The Export window opens. The first time, a message about password protection appears; click Continue.
  2. Click Entire file, or Selected individuals to choose people.
  3. Choose a GEDCOM option from the Output format list.
  4. Choose what to include. Leave Privatize living people unticked if you want living relatives’ first names on the chart. Media files are not needed.
  5. Leave Export as password protected ZIP file unticked. Gildroot can open a .zip, but not one locked with a password.
  6. Click OK. In the Export to GEDCOM window, keep the Destination and Character set as they are, and click OK.
  7. Type a name for the file, choose where to save it, and click Save. A message tells you when it is done.

Stuck?

Still stuck after these? Write to support@gildroot.com and say which step. Please don’t attach your file; we never need it.

I made a password-protected ZIP by mistake.

Export again with Export as password protected ZIP file unticked. Or unzip it yourself with the password, and drop the .ged file inside into Gildroot.

Living people have no first names.

Privatize living people was ticked. It exports surnames and relationships but not first and middle names or facts. Export again with it unticked.

My tree is synced with Ancestry.

You can export from Family Tree Maker as above, or from the Ancestry website with the Ancestry guide. Both give a GEDCOM file.

Gildroot reads the text encodings family tree programs use (UTF-8, UTF-16, ANSEL and the older Windows and Mac sets) and works out which one a file uses. If a name still looks wrong in the studio, you can correct it there; your original file is never changed.

My photos are missing.

A GEDCOM file holds names, dates, places and relationships as plain text. Photos stay behind. Charts don’t use photos, so nothing is lost for the chart.
